# 🎬 视频库管理

一个**单文件、零依赖、纯本地**的视频库管理工具。

所有代码都在一个 `video-master.html` 里 —— 双击就能打开使用，数据保存在你自己的浏览器中，**不需要服务器、不需要联网、不需要安装任何东西**。

## ✨ 功能

- **条目管理** —— 记录番号、名称、女优（可多个）、片商、个人评分、时间、类别、磁力链接
- **封面上传与裁剪** —— 上传图片后可拖动裁剪框、拖四角调整大小，按 16:10 比例裁切；也可以跳过裁剪直接用整张图
- **类别管理** —— 自由新建 / 重命名 / 删除类别，重命名会自动同步到所有关联视频
- **搜索** —— 在番号、名称、女优、片商、时间中全字段模糊搜索
- **排序** —— 最新添加、时间新→旧、时间旧→新、评分高→低、评分低→高
- **详情与预览** —— 点击卡片查看详情，点击封面全屏放大（灯箱）
- **一键复制磁力链接**
- **导入 / 导出 JSON 备份**
- **响应式** —— 手机浏览器上同样可用，界面针对窄屏做了适配
- **深色主题**

## 🚀 快速开始

1. 下载或克隆本仓库：

   ```bash
   git clone https://github.com/z34ii/video-master.git
   ```

2. 双击打开 `video-master.html`，浏览器里就能用了。

> 💡 如果你发现数据保存不成功，说明你的浏览器对 `file://` 协议下的本地存储支持有限制。改用下面任意一种方式即可：
>
> - 起一个本地静态服务器，例如 `python -m http.server 8000`，然后访问 `http://localhost:8000/video-master.html`
> - 或者部署到 GitHub Pages（见下文）

### 部署到 GitHub Pages（可选）

仓库的 **Settings → Pages → Source** 选择 `Deploy from a branch`，分支选 `main`、目录选 `/ (root)`，保存后等待一两分钟，即可通过下面的地址访问：

```
https://z34ii.github.io/video-master/video-master.html
```

> ⚠️ 注意：`file://` 打开和 GitHub Pages 打开属于**两个不同的存储空间**，之前存的数据不会自动带过去。如果要从一个换到另一个，先「导出」备份再在新地址「导入」。

| 操作 | 位置 |

| 添加视频 | 右上角 **＋ 添加** |
| 编辑 / 删除 | 每张卡片底部的 **编辑** / **删除** 按钮 |

## 💾 数据存储与备份

**这一点很重要，建议看完。**

数据**只保存在当前浏览器的 localStorage 里**，键名为 `videoMasterData_v2`。这意味着：

- ❌ 换一台电脑、换一个浏览器、清除浏览器数据 → **数据就没了**
- ❌ 不会同步到任何云端，别人打不开你的数据
- ❌ 手机和电脑之间数据不互通
- ⚠️ localStorage 的容量上限通常在 **5MB 左右**（各浏览器略有差异）。封面图是以 base64 形式存进去的，所以图片存多了、存大了，可能会撑满

**所以请养成定期备份的习惯**：点右上角 **导出**，会下载一个 `视频库备份_日期.json` 文件，把它存到安全的地方（网盘、U 盘都行）。需要时用 **导入** 恢复。

> 导入会**覆盖**当前所有数据，操作前会有确认提示。

图片处理策略（代码内置，无需配置）：

- 原图上传时压缩到最大宽度 **1280px**、JPEG 质量 0.8
- 卡片用的缩略图最大宽度 **480px**、JPEG 质量 0.82

## 🔧 技术说明

- 原生 JavaScript（ES5 风格写法），**无任何第三方依赖**
- HTML / CSS / JS 全部内联在同一个文件里，方便直接分发和离线使用
- `localStorage` 做数据持久化
- Canvas API 处理封面的缩放与裁剪
- Pointer Events 实现裁剪框的拖拽与四角缩放

## ⚠️ 已知限制

- **数据不跨设备**：单浏览器本地存储，没有云同步、没有多端共享
- **容量有限**：受 localStorage 约 5MB 上限约束，不适合存放大量高清封面
- **磁力链接仅作记录**：本工具只在条目里保存磁力链接文本，方便你复制，**自身不下载、不解析、不播放任何内容**
- 没有内置的回收站，删除操作需要二次确认后才会执行
